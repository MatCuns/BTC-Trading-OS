# Contributing

Start with [AGENTS.md](AGENTS.md) and [docs/STATUS.md](docs/STATUS.md). The current repository is a documented product foundation, not a working trading release.

## Change workflow
1. Describe the observable behavior, failure cases and relevant environment.
2. Work on a focused branch, preserving human changes and operating data.
3. Implement the change and verify the affected contracts.
4. Update STATUS and CHANGELOG; update architecture/operations/OKX compatibility where relevant.
5. Open a PR with actual test evidence and server checks still required.

The owner's development agents may merge their own requested work after applicable checks under the authorization in AGENTS.md. This does not authorize merging unrelated contributions, bypassing branch rules or placing live orders.

See [DEVELOPMENT](docs/DEVELOPMENT.md) for addition/removal procedures and [START_HERE](docs/START_HERE.md) for the owner's next step.
